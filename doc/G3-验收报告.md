## 四、决策关闭记录

- **DEC-07**（锚点坐标字段）：拍板增加 `anchor_start/anchor_length/anchor_context_hash`（nullable，migration v2 ALTER TABLE）→ **ADR-003 已定稿**（`adr/ADR-003-anchor-fields.md`）；坐标语义=渲染后纯文本 Character 偏移，三级降级规则（坐标切片→hash 搜索→降级消息）。
- **DEC-05**（压缩阈值）：**32_000 字符**（G0 实测 128KB 无截断，取显著低一档），实现说明记于 `BranchContextAssembler.swift` 头注。
- **DEC-06**（摘要 session 策略）：**临时独立 ACP session**（用完即摘映射，不污染主线/支线历史），`ACPSummarizer` 实现，真实 CLI 实测通过。

## 五、已知限制与后续项（不阻塞 G3）

- 浮动「追问」入口为右下角固定胶囊，贴选区 firstRect 定位列为工程候选（工程笔记）；GUI 目视冒烟（入口观感/回跳动效/标签交互）留用户过一轮。
- exact 范围级回跳高亮为 stretch（当前整消息高亮 1.2s 渐隐，resolution 已在回调载荷留口）；嵌套锚点回跳降级为切父标签+滚动。
- Assembler 祖先块「首条提问」当前取支线首条 user 消息（即 seed），产品是否跳过 seed 归 B-M4 一并定（BR-09 测试期间发现，已记录）。
- UI 关闭的标签会话内无重开入口（数据不动，重启恢复），重开入口归 B-M4 树面板。
- ToolCallCard 折叠态选区坐标相对截断文本（代码注释已注明，锚点消费侧以 quote 匹配为主）。
- coordinator failed 记录无清理 API（内存驻留供重试），B-M4 恢复策略定稿时再评估。
