  最近活动排序/恢复选中/重命名。删除/归档/跨线程移动支线/合并线程**不做**（§8.4 排除项维持）。

## 6. 真实 CLI 验收记录（用户 2026-08-02 批准，约 5 次最小化 prompt 含排障复测）

- `sessionResumeRealCLI`（REC-01）：两段式——首段发「请只回复两个字：续接」完成并落映射；
  模拟重启后 `openRestoredOrCreate` → `supportsLoadSession=true` → recovery=sessionResumed、
  历史呈现、追问「请只回复两个字：成功」在原 session 完成、映射未变。结果：**通过**（9.8s）。
  排障：首两轮因 kimi 0.31.1 的 `session/load` 要求 `mcpServers` 必填且响应无 `sessionId`
  （SDK `SessionLoad` 不兼容）失败；改自定义 `TwigSessionLoad` 后通过，协议事实已补记 g0-findings §2。
- `sessionResumeUnavailableRealCLI`（REC-02）：映射指向不存在 session → recovery=sessionUnavailable、
  历史无损、退化新建后「请只回复两个字：降级」完成。结果：**通过**（5.5s）。
- 环境备注：验收期间 CLI 为 **0.31.1**（基线 0.31.0），握手/load/降级行为一致，兼容矩阵已补记。
