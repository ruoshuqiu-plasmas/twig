## 2026-07-31（B-M1 期间）

- **swift-testing 派生子进程假死**：高度并发 spawn 时子进程卡在 dyld 启动通知阶段（`dyld4::RemoteNotificationResponder::blockOnSynchronousEvent`，sample 实证，与业务代码无关）。凡派生真实子进程的测试套件必须标 `@Suite(.serialized)`。
- **Process dealloc 陷阱**：Process 运行中 dealloc 抛 NSException；等待子进程退出必须全程挂起，返回前确保已退出。
- **acp-swift-sdk JSON 转义**：其 JSONEncoder 把 `/` 转义为 `\/`（`session\/new`），fake agent 按字面 `session/new` 匹配会永不应答、测试挂死——含斜杠 method 须双写法兼容。
- **SDK request id 混用**：initialize=1 为数字，`session/new` 起为 UUID 字符串；fake agent 回显须两种都容忍。
- **swiftpm-testing-helper FD 泄漏**：helper 与测试同进程，孙进程（bash fake agent）继承管道 FD 会让 helper 永远等不到 EOF——supervisor deinit 加 SIGKILL 兜底解决。
- **swift-testing 下自制 withTimeout**：不能用任务组实现（任务组隐式等待不响应取消的子任务），须非结构化竞速。
- **GRDB 7 重载解析**：同名同步/异步 `read`/`write` 重载在 async 上下文优先选异步版，测试直调 db 须 `await`。
- **SQLite 外键顺序**：外键开启时 CREATE TABLE 不得引用未创建的表。branches.anchor_message_id 与 messages.branch_id 循环引用 → anchor FK 不建，由应用层保证。
- **GRDB 离线播种（网络受限期）**：github.com 大传输反复断流（ls-remote 小包正常，浅克隆镜像 15 次重试均失败），最终用户手动下载官方 v7.11.1 zip（commit b83108d1），经 jsDelivr 官方清单 SHA-256 逐文件校验 229/229 一致后建本地镜像播种 SPM 缓存 + insteadOf 离线 resolve（配置已还原）。
- **⚠️ 推送前收尾（pending）**：Package.resolved 中 GRDB revision `351f0f6f` 为本地合成哈希；网络稳定后须删除 .build 与 SPM 缓存中的 GRDB，`swift package resolve` 换真实哈希 `b83108d1`，复跑测试再推送。
